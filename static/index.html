Como usar e navegar pelo teclado
  1. Inicie a conversa e permita o microfone. Fale uma pessoa por vez.
  2. Ao parar, aguarde a última atualização. Use Revisar texto para corrigir palavras.
  3. Salve ou copie a conversa antes de sair.

Use Tab e Shift+Tab para percorrer os controles, Enter ou Espaço para ativar botões e setas para alterar seleções. Na área das legendas, use as setas para rolar. Escape fecha as caixas de diálogo e sai da leitura ampliada.

A leitura automática pode ser desligada nas preferências. Ao rolar para trechos anteriores, a rolagem automática é suspensa até você voltar ao fim. O microfone para se a aba ficar em segundo plano. Cada sessão dura até 30 minutos; inicie outra para continuar sem apagar o texto.
